`집계 함수`

```
COUNT()    -- 개수
AVG()      -- 평균
SUM()      -- 합계
MAX()      -- 최댓값
MIN()      -- 최솟값
```

`집계 함수와 NULL`

집계 함수를 사용하는 컬럼에 있는 NULL이 있는 경우. NULL을 제외하고 계산 됨.
